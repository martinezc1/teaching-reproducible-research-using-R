2  Assignment 2: Exploring Pixar with the Tidyverse

2.1 Overview

This assignment continues our introduction to the Tidyverse using data from the pixarfilms package.

The pixarfilms package contains several datasets describing Pixar movies, including their genres, box-office performance, audience responses, and release information.

You will use these datasets to answer a series of questions about Pixar’s history and films.

2.2 Learning Objectives

By completing this assignment, you will be able to:

  • Use dplyr verbs such as select(), distinct(), mutate(), count(), group_by(), summarize(), and arrange() to explore data
  • Identify unique values within a dataset
  • Create new variables from existing variables
  • Use case_when() to recode categorical information
  • Identify the highest and lowest values using slice_max() and slice_min()
  • Calculate grouped summary statistics
  • Apply Tidyverse skills to a new dataset independently
  • Develop and answer your own data-driven question

2.3 Textbook Connection

This assignment builds directly from Chapter 2: Introduction to tidyverse in Reproducible Research Using R.

Students are encouraged to review the chapter and the code we worked through together in class before beginning this assignment.

2.4 Submission Instructions

Submit one .R script file.

Your script must:

  • Run from top to bottom without errors
  • Include clear section comments for each question
  • Save newly created datasets when instructed
  • Contain your written responses as comments where requested

Begin your script by loading the packages needed for this assignment:

library(tidyverse)
library(pixarfilms)

3 Assignment Tasks

3.1 1. Exploring Pixar Genres

The genres dataset contains the genres associated with each Pixar film. Notice that a movie can appear more than once because a single movie may belong to multiple genres.

3.1.1 1.1 What Genres Appear in Pixar Films?

First, let’s find out which genres appear in the dataset.

Using the genres dataset:

  1. Use distinct() to identify the unique genres represented in Pixar films.
  2. Determine the total number of distinct genres.
  3. Arrange the unique genres alphabetically.

Question: How many distinct genres appear in the dataset?

3.1.2 1.2 How Many Genres Does Each Film Have?

Next, investigate how many genres are associated with each Pixar film.

Using the genres dataset:

  1. Count the number of genres associated with each film.
  2. Arrange the results from the greatest number of genres to the fewest.
  3. Save the result as film_genres.

Question: Which Pixar film or films are associated with the greatest number of genres?

3.2 2. Which Pixar Films Made the Most Money?

The box_office dataset contains information about the production budget and box-office performance of Pixar films.

For this assignment, we will estimate how much money a film made by subtracting its production budget from its worldwide box-office revenue.

Using box_office:

  1. Use select() to keep only the following variables:

    • film
    • budget
    • box_office_worldwide

  2. Use mutate() to create a new variable called net, calculated as:

    worldwide box office - budget

  3. Save the resulting dataset as pixar_money.

  4. Using slice_max(), identify the three films with the highest net.

  5. Using slice_min(), identify the three films with the lowest net.

Questions:

  • Which Pixar film had the highest estimated net?
  • Which Pixar film had the lowest estimated net?
Note

For this assignment, net is a simplified measure of financial performance. A film’s production budget and worldwide box-office revenue do not account for all costs or sources of revenue.

3.3 3. Turning cinema_score Grades into Numbers

The public_response dataset contains several measures of how Pixar films were received by critics and audiences.

One of these variables is cinema_score, which uses letter grades such as "A+", "A", "A-", and so on.

Let’s convert these letter grades into numeric scores.

Using the public_response dataset:

  1. Use mutate() and case_when() to create a new variable called cinema_numeric.
  2. Use the grading scale from our course syllabus to determine the numeric value associated with each letter grade.
  3. Save the resulting dataset as pixar_scores.
  4. Calculate the average numeric cinema_score across Pixar films.
  5. Identify the three films with the highest numeric cinema_score.
  6. Identify the three films with the lowest numeric cinema_score.

Questions:

  • What was the average numeric cinema_score for Pixar films?
  • Which films received the highest converted scores?
  • Which films received the lowest converted scores?

3.4 4. Pixar Through the Decades

The pixar_films dataset contains basic information about Pixar’s films, including their release dates and runtimes.

We want to investigate how Pixar’s films have changed across decades.

3.4.1 4.1 Create a Decade Variable

Using pixar_films, use mutate() to create a new variable called decade based on release_date.

Your categories should identify films as belonging to the:

  • 1990s
  • 2000s
  • 2010s
  • 2020s

Save the resulting dataset as pixar_decades.

3.4.2 4.2 Summarize Pixar Films by Decade

Next, group the films by decade and calculate:

  • Number of films
  • Mean runtime
  • Median runtime
  • Minimum runtime
  • Maximum runtime

Arrange the resulting table from the most recent decade to the oldest.

Save this summary as decade_summary.

Question: Based on your summary, do Pixar movies appear to have become longer, shorter, or stayed approximately the same length over time? Briefly explain your answer as a comment in your script.

3.5 5. Pixar Data Challenge

Now it’s your turn!

Using any dataset in the pixarfilms package, come up with one question about Pixar that you find interesting.

Some possibilities include questions about:

  • Box-office performance
  • Genres
  • Movie ratings
  • Academy Awards
  • Release dates
  • Runtime

You are not limited to these topics.

Write your question as a comment in your script.

Then:

  1. Use at least three Tidyverse functions to investigate your question.
  2. Show the code used to answer it.
  3. Write 1–2 sentences as comments explaining what you found.

4 Reflection

At the end of your script, answer the following questions as comments:

  • Which Pixar film is your favorite? (There is no wrong answer… probably.)

5 Reproducibility Practice

This assignment focuses on creating a clear and reproducible data-analysis workflow.

In your script:

  • Use section headers that match Questions 1–5.
  • Give newly created objects clear and meaningful names.
  • Do not overwrite the original datasets from the pixarfilms package.
  • Use View(), glimpse(), summary(), count(), or other checkpoint functions when helpful to inspect your work.
  • Make sure your completed script runs from top to bottom without errors.

Remember: the goal is not simply to get an answer. Your code should make it possible for someone else to understand how you got there.
